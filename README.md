# Spatio-Temporal Traffic Speed Forecasting on METR-LA

Forecasting freeway speeds 5–60 minutes ahead at 207 loop detectors in Los Angeles.
The project compares a ladder of models, from a historical average to a graph neural
network (Graph WaveNet), on the standard METR-LA benchmark. It also covers
leakage-tested feature engineering and statistical significance testing.

## Quick start

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"            # or: pip install -r requirements.txt && pip install -e .
pytest                             # 23 unit tests, a few seconds

python scripts/run_eda.py          # EDA figures and statistics       (~1 min)
python scripts/run_classical.py    # baselines + feature models        (~40 min, CPU)
bash scripts/run_deep_experiments.sh   # LSTM, Graph WaveNet, ablation (~4 h on Apple M3 / MPS)
python scripts/evaluate.py         # tables, significance tests, figures
cd report && tectonic main.tex     # or latexmk -xelatex main.tex
```

Training picks CUDA, then Apple MPS, then CPU automatically. Model checkpoints go
to `checkpoints/` (git-ignored). Test-set predictions are written to
`results/predictions/` (git-ignored because of their size) and are regenerated by
the scripts above.

## Method in brief

* **Protocol:** 12 input steps → 12 output steps; chronological 70/10/20 split;
  masked metrics that ignore missing (zero) targets. This is the same protocol as
  DCRNN and Graph WaveNet, so the numbers are directly comparable.
* **Data quality:** 8.1 % of readings are missing (encoded as 0). They are masked in
  losses and metrics, and causal forward-fill is used for features only.
* **Features:** lags, rolling statistics, missing-data indicators, sin/cos calendar
  of the target time, the sensor's weekly profile and current anomaly, and
  upstream/downstream graph aggregates. All are causal and unit-tested for leakage.
* **Models:** Historical Average, Persistence, Ridge, histogram gradient boosting
  (direct multi-horizon), node-shared LSTM, Graph WaveNet (diffusion convolution
  + adaptive adjacency + gated dilated causal convolution).
* **Validation:** hyper-parameters selected on the validation split, Diebold–Mariano
  tests with Newey–West variance, day-level block-bootstrap confidence intervals,
  Graph WaveNet spatial ablation, and error analysis by horizon, hour, sensor and
  missing input.
